## Сводка на 23.10.2026 (версия 1.10.0)

**Сделано** (подробности — в разделах ниже):
- Windows-приложение **Oni**: установщик и portable-версия, автообновление (`npm run release`),
  вход под своим аккаунтом Яндекса, трей, кнопки в превью панели задач, окно запоминает
  размер, мини-плеер поверх окон, журнал ошибок и экран ошибки вместо пустого окна.
- Оформление по макету пользователя: иконка-маска, японский стиль, палитра пользователя,
  фон-картина «Blood Moon Over Misty Pagodas» (окно, баннер, плеер), сворачиваемое меню,
  прозрачность окна (Acrylic), живые видеообложки Яндекса, пульсация обложек в такт (трекер ритма).
- Музыка: «Моя волна» с фильтром повторов, радио от трека / исполнителя / альбома / плейлиста,
  «Похожие», лайкнутые плейлисты, история (своя и Яндекса), отчёты о прослушивании,
  настройки звука: качество и 10-полосный эквалайзер с пресетами (включая «Мой»).
- Рекомендации в духе Spotify: Daylist под время дня, миксы по жанрам, «Открытия недели», «Радар новинок»,
  «На повторе», «Забытые хиты», «Потому что вы слушали…», умное перемешивание (✦),
  персональные плейлисты Яндекса, метрика «Как работают рекомендации».
- Навигация назад/вперёд: кнопки мыши 4/5 и Alt+←/→. Интерфейс на русском и английском.
- Тесты: `npm run check` (типы, линтер, офлайн-тесты волны, рекомендаций, ритма) и
  `npm run test:e2e` (37 шагов UI, 7 — оконной оболочки, 3 — автообновления, 2 — входа; на реальном аккаунте).

## Этап 1. Стабильность

Цель: любая ошибка видна и не убивает окно, установщик собирается.

- [x] **ErrorBoundary.** Упавшая страница показывает карточку ошибки, а боковая
      панель и плеер продолжают работать. Если упал весь интерфейс — экран
      «Что-то пошло не так» с кнопкой «Перезагрузить». Покрыто e2e-шагом.
- [x] **Журнал ошибок.** Ошибки интерфейса и main-процесса пишутся в
      `userData/logs/wave.log` (до 1 МБ плюс один предыдущий файл). Упавший процесс
      отрисовки main перезагружает сам. Кнопка «Открыть журнал» — в настройках
      и на экране ошибки.
- [x] **Запуск как обычной программы (.exe).** `npm run dist` собирает в `release/`
      установщик `Wave-Setup-<версия>.exe` (NSIS: ярлыки на рабочем столе и в «Пуске»,
      удаление через «Параметры → Приложения») и `Wave-<версия>-portable.exe`.
      Нарисована иконка (`build/icon.png`, `build/icon.ico`), сборка вынесена в `release/`,
      чтобы не конфликтовать с `dist/` от Vite. Зависимости интерфейса перенесены
      в devDependencies: Vite встраивает их в бандл, и в установщик не попадает лишний
      `node_modules`. Задан AppUserModelID для панели задач.
- [x] **Линтер.** `npm run lint` — oxlint (typescript-eslint не поддерживает
      TypeScript 7, а oxlint не зависит от пакета `typescript`). Правила хуков React
      плюс своё правило `wave/effect-block-body` (`lint/wave-plugin.js`): эффект с
