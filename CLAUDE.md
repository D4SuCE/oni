# Oni — правила работы для Claude

Источник правды между сессиями — **файлы в репозитории**: этот (правила, решения, предпочтения; Claude Code
читает его сам при каждом запуске) и `ROADMAP.md` (где мы сейчас и что дальше). Память Claude Code — только
дополнение и указатель на эти файлы: если они расходятся, верны файлы. Оба файла держать короткими: этот файл
читается целиком в каждой сессии, подробности — в `docs/`, сделанное — в `docs/history/`.

## Что и где записывать (чтобы после перезапуска всё было известно)

| Что произошло | Куда записать |
| --- | --- |
| Задача начата / сделана / отложена | сводка в начале `ROADMAP.md` + пункт в нужном разделе |
| Изменение, которое увидит пользователь | `CHANGELOG.md`, «Не выпущено» (при выпуске — раздел версии) |
| Решение или предпочтение пользователя | этот файл, «Решения и предпочтения» (коротко) |
| Новое правило работы | этот файл, «Как ведём работу» |
| Окружение, секрет, адрес, аккаунт | `docs/environment.md` (здесь — одна строка, если это нужно каждой сессии) |
| Почему сделано именно так | сообщение коммита и комментарий в коде |
| Раздел ROADMAP целиком сделан | перенести в `docs/history/` (в ROADMAP — одна строка) |

Записывать в том же коммите, что и саму работу, и отправлять в `origin` — тогда на GitHub всегда актуальное состояние.
Каждый план и решение — в файлы: пользователь хочет быть уверен, что после перезапуска всё известно.

## С чего начать

0. Открытые задачи сторожа: `gh issue list --label ym-watch -R D4SuCE/oni` — рассказать пользователю, что нашёл
   и сделал облачный агент (комментарии в задаче), если он ещё не знает. Так же — автопилот (метка `autopilot`,
   через REST: `gh api 'repos/D4SuCE/oni/issues?labels=autopilot'`).
1. **`ROADMAP.md`**: сводка — что есть, что в работе, что дальше.
2. `CHANGELOG.md`, «Не выпущено» — что влито в `main`, но не выпущено.
3. Подробности — `docs/` (`environment.md`, `recommendations.md`, `ios-signing.md`, `autopilot.md`, `other-clients.md` — разбор чужих клиентов), разборы и доводы
   прошлых задач — `docs/history/roadmap-2026-10.md`, прежний полный текст этого файла — `docs/history/claude-md-2026-10.md`.

## Как ведём работу

- Одна задача — одна ветка `feat/…`, `fix/…` или `chore/…` и PR в `main` (`gh pr create`; в облаке, где GraphQL
  закрыт, — REST, см. `watch/AGENT.md`). Прямая запись в `main` закрыта правилом репозитория (28.10.2026): слить
  можно только PR с зелёной проверкой `check`. Сливает Claude сам — `gh pr merge --squash --delete-branch`
  (решение пользователя 28.10.2026), после — проверить CI (`gh run list`).
- Готово = проходят `npm run check` и `npm run test:e2e` (на реальном аккаунте, нужен `YANDEX_MUSIC_TOKEN`;
  один шаг — `E2E_ONLY=<часть названия>`), пункт в ROADMAP отмечен, строка в CHANGELOG. iPhone-правки — плюс
  облачная проверка `gh workflow run ios.yml --ref <ветка>` (один раз на партию правок перед выпуском).
- Баг, найденный вручную, сначала воспроизводим тестом, потом чиним.
- Форматтер (`prettier`) не запускать: настроек у проекта нет, он переписывает код в чужой стиль (одинарные кавычки и
  длинные строки — как в остальном коде; проверка — `npm run lint`, это oxlint).
- Тесты не оставляют изменений в реальном аккаунте: лайки, переименования и т. п. сразу откатываются (в `finally`).
- Выпуск: раздел в CHANGELOG → `npm version x.y.z --no-git-tag-version` → PR с названием «Release x.y.z» → слить
  (squash). Метку `vx.y.z` ставит `tag-release.yml` и запускает `release.yml` (Windows-сборка → oni-releases, затем
  ждёт `ios.yml`, прикладывает IPA и обновляет `sidestore.json`); следить — `gh run watch`. Метку руками не ставить.
  `npm run release` на ПК — запасной путь. Подробно — README, «Выпуск версии».
- e2e на машине GitHub (Windows): `gh workflow run e2e.yml --ref <ветка>` — так проверяет облачный агент.
- «Можешь не предлагать — делай что нужно» (22.10.2026): готовое (тесты и облачная проверка iPhone прошли) вливать
  и выпускать без вопроса; спрашивать только то, что решает пользователь (вкусы, деньги, риск для его данных или
  установки). Незначительное — сразу выпускать; значимое (например, анимации) — сначала пробная сборка, выпуск после
  его выбора. Пробные выпуски — **черновиками** (`gh release create … -R D4SuCE/oni --draft`: видит
  только владелец; 28.10.2026 — прежние 13 `--prerelease` удалены, их видели все) — без отдельного вопроса.
- Полный доступ к компьютеру для работы разрешён (24.10.2026). Если автоматический режим Claude Code останавливает
  публичное действие или правку своих настроек — объяснить и попросить пользователя подтвердить (правила разрешений
  себе не добавлять).
- Чат не растягивать: одна задача — одна свежая сессия, состояние — в ROADMAP/CHANGELOG (сжатие длинного чата дорого).
- Уведомления Windows (24.10.2026): **только когда сборка выложена и её можно скачать** — выпуск в oni-releases готов
  целиком (Windows + IPA, `sidestore.json`) или пробная сборка готова. Больше ни о чём. Слать так:
  `powershell -NoProfile -ExecutionPolicy Bypass -File C:/Users/Administrator/.claude-accounts/d4suce/notify.ps1 -Title "Oni 1.x.y выложен" -Text "…"`.
- Лимиты: хук `guard.mjs` на 93% пятичасового лимита велит не начинать нового, на 97% — сохранить всё и закончить
  (желание пользователя: работать, пока лимита не станет около 97%).

## Окружение (главное; всё остальное — `docs/environment.md`)

- Код — **D4SuCE/oni**, сейчас **публичный** (минуты macOS бесплатны; вернуть в приватный — по команде пользователя).
  Выпуски — публичный **D4SuCE/oni-releases**. Токен в программу не встраивается. Секреты в код и логи не класть.
- Секреты репозитория: `YANDEX_MUSIC_TOKEN` (вход на симуляторе iPhone в CI), `RELEASES_TOKEN` (выпуски).
- CI: `check.yml` (каждый push), `ios.yml` (по метке — только IPA; проверка на симуляторе — вручную), `release.yml`,
  `tag-release.yml`, `e2e.yml`, `ym-watch.yml` (сторож, 09:00 UTC).
- Папка данных Windows-версии — `%APPDATA%/Wave` (старое имя, менять нельзя: потеряются вход и история).
- Сборка для себя: `npx electron-builder --win -c.directories.output=release/oni`; сборки не копить.
- Oni ведётся с аккаунта Claude **d4suceusa@gmail.com** (`claude d4suceusa`): облачные routine, окружение, лимиты.
- Автопилот (две routine «Oni — разработка») **выключен с 25.10.2026 11:57 МСК**; включить — по команде пользователя.
  Метки `vX.Y.Z` облако создать не может (выпуск — через `tag-release.yml`).
- Официальное приложение Яндекс Музыки стоит у пользователя (`%LOCALAPPDATA%/Programs/YandexMusic`): адреса
  неизвестных запросов API — в его `resources/app.asar`.

## Решения и предпочтения пользователя

**Платформы и установка**
- iPhone — через **SideStore** (бесплатный Apple ID), не TestFlight. Apple Watch — не предлагать (нужен платный аккаунт).
- iPhone играет своим плеером iOS (AVAudioEngine + системный эквалайзер), не WebKit. Обновления на iPhone — сообщение
  и кнопка, открывающая SideStore с IPA; «Автообновление» открывает SideStore само. LocalDevVPN включают «Команды».
- Подпись программы для Windows — не делаем (платно).
- Выпуски отдельно от кода (токен не встраивается); репозиторий публичный на время разработки.
- Два репозитория остаются (28.10.2026): `oni` — код с README для разработчика, `oni-releases` — витрина
  и обновления (установленные программы ищут их там). Лицензии у кода нет (все права сохранены).

**Внешний вид**
- Японский стиль, палитра: фон #090909, панель #171514, стекло #211816, красный #D9272E / #8E171B, золото #C79A54,
  текст #F2EEE8 / #A7A3A0, обводки #49403D.
- Не нравятся: красные ползунки с золотым ободком, системные выпадающие списки. Ручка ползунка (красная, как
  в эквалайзере) — только при наведении.
- Кнопок «назад / вперёд» нет — только мышь 4/5 и Alt+←/→.
- Обложки «Открытий недели» и «Радара» — нарисованные (арта не будет).
- iPhone — минимализм как у Яндекс Музыки: 4 вкладки внизу, поиск значком вверху справа; трек — одним нажатием,
  меню — долгим; без лупы; подписи к кнопкам — только подсказка удержанием. Стили iPhone — только под `html.ios`:
  вид на ПК (и узкого окна) не менять.
- Анимации: фусума, свиток, каскад, круги на воде (включены); лепестки, ханко, тушь — убраны.
- Виджет iPhone: кнопки не открывают Oni — голый `Button(intent:)` с `.buttonStyle(.plain)`, без
  `.invalidatableContent()` и `.widgetAccentable()` на подписи; «Моя волна» открывает Oni; «Что играет» — через App Group.
- Меню трека повторяет официальное приложение (у своих mp3 — короткое меню).

**Музыка и рекомендации**
- Рекомендации — уровня Spotify. Фильтр повторов «Моей волны» — общий для аккаунта.
- Эквалайзер — 10 полос на обеих платформах.
- Скачивание списков — сверху вниз; на треке кружок, пока качается, стрелка — когда скачан.
- Без сети — как в Яндекс Музыке: «Мне нравится», скачанные играют в своих плейлистах, «Скачанное» — вкладка;
  обрыв сети во время волны — скачанные вперемешку, потом снова волна.
- «Пропущенное»: дважды пропущенные в первые 30 с и ни разу не дослушанные уходят из подборок и «Моей волны»;
  автоматические — на полгода, скрытые вручную — насовсем.
- Тексты: нет у Яндекса — из LRCLIB (все языки); Genius — только кнопкой в браузер.
- Загруженные mp3, узнанные Яндексом, — связаны с каталогом, но **не заменяются** треком каталога.
- История: вкладки «Oni» и «Яндекс Музыка»; пишется по ходу (5 с / 30 с); общая для ПК и телефона через **папку
  приложения на Яндекс Диске** («Приложения/Oni», ClientID `e3a9ad75307d4369a7b9250d0be40af2`, секрет не нужен;
  для тестов — `YANDEX_DISK_TOKEN`). Свой сервер и скрытый плейлист — отвергнуты.
- Пульт ПК ↔ телефон: максимально быстро — прямая связь по домашней сети, Диск — запасной; на iPhone после паузы
  Oni держится «на связи» **10 минут**. Одна кнопка «Отключиться» (устройство возвращается к своему, на паузе),
  только устройства с открытым Oni, громкость с пульта. Ynison аккаунту недоступен.
  **25.10.2026, полный пульт:** пока устройство подключено пультом, всё, что на нём включают (плейлист, альбом, подборка,
  трек из поиска, «Моя волна» и её настройки, радио, «Своя волна»), играет на том устройстве, которым управляют, и видно
  там; играть у себя — после «Отключиться». (Заменяет прежнее «включили своё — играет здесь».)
- Ровная громкость — только общий уровень трека, без сжатия; тихое поднимается без искажений; альбом — одним уровнем.
- Умные плейлисты — отдельный раздел на главной: «Лайки за месяц», «Новинки моих артистов», «Самое слушаемое»
  (только когда больше половины не в «На повторе»), «Лайки год назад». «Давно не слушал» — убран (копия «Забытых хитов»).
- Не нужны: эквалайзер под наушники, «Волна в дорогу», Last.fm; будильник, копия плейлистов на Диск, «Угадай
  мелодию», вибрация в такт, карточка для сторис, живой экран плеера (26.10.2026).
- Пульс обложки — только на удар бочки, не угадывание ритма (26.10.2026).
- Esc закрывает поиск (слева) и поиск в плейлисте (26.10.2026).
- Виджет iPhone (средний) — как плеер Пункта управления, в цветах Oni, в углу ♥ (27.10.2026). Системный плеер
  Пункта управления перекрасить нельзя.
- iPhone: свайп по треку на нижней панели — следующий / предыдущий трек (не перемотка), как в ЯМ (26.10.2026).
- Перенос плейлистов из других сервисов — в 2.0.0; без скачивания песен оттуда.
- Ссылки «Открыть в Oni» (29.10.2026): `https://oni-music.github.io/#track/<id>` (организация **oni-music**, страница —
  `site/`, `npm run site`); трек по ссылке сразу играет; сама в Яндекс Музыку страница не уводит — Oni открывается
  сам, только если на этом устройстве уже нажимали «Открыть в Oni».
- План 28.10.2026: ссылки «Открыть в Oni» — `https`-страница → `oni://` (не буфер обмена, не «Команды»); 3.0.0 —
  совместное прослушивание (Wi-Fi + Диск, сервер у начавшего, iPhone тоже); Mac — позже; Android — когда-нибудь.
  Пересылка трека другу — не нужна (похоже на мессенджер).
- «Своя волна» — последней, через пробную сборку; выпуск — 2.0.0.
- «✦ Загруженное» друга — только кнопкой на странице плейлиста, не в меню «…» (28.10.2026).
- Ссылка на папку «shared» в описаниях плейлистов — постоянная, во всех плейлистах; по выбору плейлистов и «Сменить
  ссылку» — не нужны (28.10.2026; спрятана, но не зашифрована — код открытый).
- Идеи из новых версий Яндекса (сохранённые волны, «поделиться волной», мастер вкуса) — не интересны (25.10.2026).

**Сторож Яндекс Музыки** — полностью автоматический, в облаке (`watch/AGENT.md`). **Условие пользователя:** код
меняется и версия выпускается, только если агент сам доказал, что без правки Oni сломается (Яндекс может выпустить
сырой патч — повторять нельзя). Интересное — не встраивать: в ROADMAP («Идеи от сторожа») и сообщить комментарием
в задаче с меткой `ym-watch`.
