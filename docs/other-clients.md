## «Без цензуры»

mashiro берёт `https://raw.githubusercontent.com/Hazzz895/FckCensorData/main/list.json`:
`{ "tracks": { "<id трека>": "<ссылка>" } }`, 1516 треков (кеш на сутки, свой список замен поверх).
**По ссылке лежит сам mp3** (проверено: `tracks/88057589` — MP3, 1,9 МБ) — нелицензионные копии чужих песен
на GitHub. **В Oni не берём** (это раздача пиратских копий).

Честный путь для Oni: у трека с `contentWarning !== 'explicit'` поискать в каталоге Яндекса тот же трек
(название + исполнитель, длительность ± 2 с) с `contentWarning === 'explicit'` (другой релиз, альбом-«explicit»)
и играть его; переключатель в настройках, «оригинал» для отдельного трека — в меню. Подбор — как в
`src/import/match.ts`.

## Метка ИИ-музыки

slopless.art (открытый, GPL-3.0), без ключа:
- `GET https://slopless.art/api/artist/<id>` → `{ aiTracks, totalTracks }`; mashiro считает исполнителя ИИ, если
  `aiTracks / totalTracks >= 0.05`;
- `GET https://slopless.art/api/track/<id>` → `{ score, scoreYandex, … }`, `score` −1 — не проверен; ИИ — `score > 0.5`.

mashiro: кеш в памяти, запросы по одному. Для Oni: кеш на устройстве (неделя), запрашивать только для того, что
на экране и в очереди «Моей волны»; пометка у исполнителя и трека; по желанию — пропуск и «Не рекомендовать»
(обратная связь волне). Сервис сторонний: недоступен — без метки, ничего не ломается. Отправляем ему только
номера треков/исполнителей.

## Текст, заливающийся по словам

Aria: текст от Яндекса — `GET tracks/<id>/lyrics?format=LRC&timeStamp=…&sign=…` (подпись, как у нас), иначе
LRCLIB. Время слов есть, только если в LRC «расширенные» метки `<мм:сс.xx>` перед словами (`LrcParser.kt`,
`WORD_TIME`) — редко. Иначе строка заливается **по доле букв**: прогресс строки = (сейчас − начало) /
(конец − начало), закрашено `прогресс × длина текста` символов (`FlowLyrics.kt`, `softReveal`, мягкий край).
Паузы между строками дольше порога — точками. Для Oni: то же — сначала метки слов, если есть, иначе по буквам.

## Слушать вместе (mashiro)

- Ведущий (хост) шлёт состояние: `{ trackId, positionMs, paused, updatedAt: Date.now(), track, queue (урезанная
  до лимита байт), index }` — полное при смене, лёгкий «пульс» без очереди чаще (`stores/together/sync.ts`).
- Гость: ожидаемая позиция = `positionMs + (Date.now() − updatedAt)`; другой трек — включить очередь и
  перемотать; расхождение больше `DRIFT_LIMIT` — перемотка. **Часы не сверяются** (считается, что совпадают) —
  у нас будет сверка часов, старт «в момент T» и мягкая подстройка вместо перемотки.
- «Готов» от каждого гостя (`reportReady`): пока у кого-то трек грузится, ведущий ждёт — берём.
- Передача ведущего (`handoff.ts`): новый поднимает комнату у себя, остальные переподключаются — берём.
- Связь: свой сервер-ретранслятор (код из шести слов, шифрование) или по локальной сети (хост слушает порт 7331,
  гости вводят IP; для интернета — VPN или проброс порта). У нас вместо сервера — Яндекс Диск, по Wi-Fi — как пульт.

## Остальное

- **Горячие клавиши** (mashiro `hotkeys.rs` — плагин global-shortcut Tauri; мод — `globalShortcuts` в настройках):
  в Electron — `globalShortcut.register`, набор и переназначение в настройках; занятые другими программами — сообщить.
- **Скорость** 0,75–1,5× (mashiro, Aria; Aria — с изменением высоты тона или без): `audio.playbackRate` +
  `preservesPitch`; на iPhone — `AVAudioUnitTimePitch` в цепочке плеера.
- **Приватный режим** (Aria): прослушивания не отправляются в Яндекс (история, обучение волны) — не слать
  `plays` / обратную связь волны, пока включён; своя история Oni — по выбору.
- **Выгрузка в CSV** (mashiro, Aria): строка на трек — название, исполнитель, альбом, плейлист, длительность,
  ссылка на Яндекс Музыку. Обратный путь у нас уже есть (`src/import`).
