# Совместное прослушивание («Вместе», 3.0.0)

Решения пользователя (29.10.2026): **все наравне** (пауза, перемотка, смена трека, что играть — у любого
участника), **без посредников** (никаких чужих серверов-пересыльщиков), участников — **несколько**.

## Как устроено

- Каждый играет со своего аккаунта Яндекса. Между устройствами ходит только «что играет»: очередь (кусок вокруг
  трека), номер трека, пауза, место в треке и **момент по общим часам**, когда это место было. Звук синхронный
  по часам, а не по скорости доставки: нажатие издалека доходит за 2–4 с, но играют все одно и то же место.
- **Общие часы:** каждое устройство сверяется с `yandex.ru/time/sync.json` (несколько замеров, берётся самый
  быстрый ответ). В одной сети гость сверяется ещё и с устройством начавшего (точнее, задержка — миллисекунды).
- **Кто прав:** состояние с самой поздней меткой времени (`rev`) побеждает. Действие любого участника — новое
  состояние. Естественный переход к следующему треку объявляет один — «ведущий» (начавший, а без него —
  устройство с наименьшим id), остальные переходят сами и подстраиваются.
- **Подстройка:** раз в полсекунды каждое устройство сравнивает своё место с общим. Расхождение больше 0,4 с —
  перемотка; меньше — чуть быстрее или медленнее (±4 %, высота сохраняется), пока не сойдутся. Задержка вывода
  звука (Bluetooth) учитывается: на iPhone — системная `outputLatency`, на ПК — `AudioContext.outputLatency`.

## Связь

- **Одна Wi-Fi сеть:** у начавшего — сервер WebSocket (ПК — `electron/together.cjs`, iPhone — `NWListener` в
  `LanPlugin.swift`), ключ — номер комнаты из приглашения. Гости подключаются напрямую; сервер пересылает
  сообщения всем. Мгновенно.
- **Издалека — Яндекс Диски участников.** У каждого, у кого подключён Диск, в папке Oni есть открытая по ссылке
  папка `together`; там файл `room-<комната>.json` — кто он и что играет, по его сведениям. Остальные читают эти
  файлы по ссылкам (без входа) каждые 2,5 с. Писать на чужой Диск нельзя, поэтому:
  - приглашение — ссылка на папку начавшего: `https://oni-music.github.io/#listen/<комната>/<папка>`;
  - у гостя есть **своя ссылка того же вида** («ответная»): начавший нажимает её один раз — и видит гостя, гость
    управляет. Узнанные так друзья запоминаются (`together.friends`): в следующий раз обмен не нужен — Oni
    начавшего сам заглядывает в папки друзей;
  - каждый пишет в свой файл всех известных ему участников с их папками — так все узнают всех через начавшего.
- Без своего Диска гость издалека только слушает (читать открытую папку можно без входа). Начать — только с
  подключённым Диском.
- Обойтись без ответной ссылки издалека нельзя (пользователь спросил 29.10.2026): писать в чужой Диск не может никто,
  а другого канала между аккаунтами без посредника нет. Поэтому гостю издалека через 8 с после входа Oni сам
  предлагает «Отправить» свою ссылку (одно нажатие); знакомым — не предлагает.

## Свои загруженные песни

Яндекс отдаёт загруженный mp3 только владельцу (пользователь спросил 29.10.2026, можно ли поставить такой в очередь).
Oni владельца кладёт его в свою папку `together` (Диск забирает файл у Яндекса сам, как в «Загруженном» друзей) —
играющий и три следующих, не весь плейлист сразу; в состоянии у трека появляется `share` (откуда брать), а пока файл
едет — его номер в `wait`, и остальные ждут на паузе. Владелец играет его сразу, остальные подтягиваются перемоткой.
Файлы убираются, когда владелец выходит из комнаты.

## Что не делаем в первой версии

- Скорость воспроизведения в комнате — всегда 1×; кроссфейд — как у каждого настроено.
- «Моя волна» в комнате: волна пополняется у того, кто её включил; ушёл он — очередь доиграет и остановится.
- Свой mp3 участника без подключённого Диска остальным недоступен — у них он не сыграет.
