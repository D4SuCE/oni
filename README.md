# Oni

Неофициальный клиент Яндекс Музыки для Windows с собственным интерфейсом:
«Моя волна» с фильтром повторов, поиск, коллекция, плейлисты, загрузка своих mp3,
синхронный текст песен. Интерфейс на русском и английском.

Electron + React 19 + Vite + zustand. Не связан с Яндексом.

## Установка как обычной программы

```sh
npm run dist
```

В папке `release/` появятся два файла:

- `Oni-Setup-<версия>.exe` — установщик: ярлыки на рабочем столе и в меню «Пуск»,
  удаление через «Параметры → Приложения».
- `Oni-<версия>-portable.exe` — один файл, работает без установки.

Установщик можно передать другому человеку: при первом запуске он увидит экран
входа и войдёт в **свой** аккаунт Яндекса. Данные каждого пользователя Windows
хранятся отдельно, токен зашифрован. Полные треки требуют подписки Яндекс Плюс.

Код не подписан, поэтому при первом запуске Windows SmartScreen может показать
«Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Выпуск версии

Номер версии — в `package.json`; его показывают настройки и имена установщиков.
Что изменилось — в [CHANGELOG.md](CHANGELOG.md).

1. Перенести пункты из «Не выпущено» в новый раздел `## [x.y.z] — <дата>` и
   поправить ссылки внизу файла.
2. `npm version x.y.z --no-git-tag-version` — меняет `package.json` и `package-lock.json`.
3. Коммит «Release x.y.z», затем `git tag vx.y.z` и `git push --follow-tags`.
4. `npm run dist` — установщики с новым номером появятся в `release/`.

## Запуск для разработки

```sh
npm install
npm start          # сборка и запуск приложения
npm run dev        # Vite dev-сервер с горячей перезагрузкой
```

В обычном браузере приложение не работает: запросы к Яндексу идут через
Electron. Чтобы открыть dev-сервер в Electron, задайте `VITE_DEV_URL=http://localhost:5173`
и выполните `npm run electron`.

Вход — через окно Яндекса или вставкой OAuth-токена. Токен хранится
зашифрованным (`safeStorage`) в папке данных приложения.

## Проверки

```sh
npm run check      # всё быстрое разом: typecheck + lint + тесты волны, рекомендаций, ритма
npm run typecheck  # TypeScript
npm run lint       # oxlint, в том числе правило lint/wave-plugin.js
npm run icons      # пересобрать иконки из design/oni-icon-1024.png
npm run test:wave  # офлайн-тесты движка волны
npm run test:api   # интеграция с API (нужен YANDEX_MUSIC_TOKEN)
npm run test:e2e   # UI-тест реального приложения (нужен YANDEX_MUSIC_TOKEN)
```

На GitHub `npm run check` и сборка запускаются на каждый push
(`.github/workflows/check.yml`); e2e — только локально.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `electron/` | main-процесс: окно, хранение токена, HTTP-запросы к Яндексу (без CORS) |
| `src/api/` | клиент API Яндекс Музыки поверх абстрактного `Transport` |
| `src/player/` | воспроизведение, очередь, Media Session |
| `src/wave/` | «Моя волна»: фильтр повторов и история прослушиваний |
| `src/views/`, `src/components/` | экраны и компоненты интерфейса |
| `src/i18n.ts` | все строки интерфейса (ru, en) |

План работ — в [ROADMAP.md](ROADMAP.md).
